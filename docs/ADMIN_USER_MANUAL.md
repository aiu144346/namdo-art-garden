## 1. 시스템 소개 및 주요 특징

본 관리자 포털은 HTML 코딩이나 복잡한 웹 에디터 사용법을 몰라도, **실무 담당자가 업무용으로 작성한 MS Word(.docx) 파일만 마우스로 끌어다 놓으면(Drag & Drop)** 홈페이지에 즉시 반영되도록 구축된 반응형 스마트 CMS(Content Management System)입니다.

### 🌟 4대 핵심 편의 기능
1. **워드(.docx) 100% 자동 파싱**: 제목, 작성일, 본문 텍스트 서식(굵게, 표, 목록), 내장 사진까지 0.5초 만에 자동 추출
2. **실시간 라이브 미리보기(Live Preview)**: 홈페이지에 실제로 어떻게 노출되는지 우측 화면에서 실시간으로 확인 후 발행
3. **즉각적인 사이트 반영**: `[발행하기]` 클릭 즉시 메인 화면의 "남도 소식 & 공지(공지사항/언론보도)" 섹션 및 리포트 목록에 최신 글 1순위 노출
4. **맞춤 보안 관리**: 담당자 전용 비밀 접속 경로(URL) 지정 및 아이디/비밀번호 자유 변경 지원

## 2. 관리자 접속 및 로그인 안내

### 1) 접속 경로 (URL)
- **공식 실서버 주소**: `https://namdoartgarden.com/admin` (도메인 뒤에 `/admin` 입력)
- **로컬 테스트 주소**: `http://localhost:5173/admin`

### 2) 사전 발급 공식 관리자 계정 (3종)
업무 역할과 책임에 따라 아래 3개 계정 중 하나를 선택하여 로그인하실 수 있습니다.

| 권한 / 역할 | 추천 대상 | 관리자 아이디 (ID) | 기본 비밀번호 (PW) |
| :--- | :--- | :--- | :--- |
| **최고 관리자 (Master)** | 발주사 총괄 팀장 / 대표 관리자 | `namdo_master` | `Namdo#Master9821!` |
| **총괄 운영자 (Manager)** | 홍보 마케팅 담당자 / 운영사 실무진 | `namdo_manager` | `Garden*Manager34!` |
| **콘텐츠 담당자 (Editor)** | 서포터즈 담당 / 공지 등록 실무자 | `namdo_manager01` | `Namdo#Edit2026$!` |

> 🔒 **보안 안내**: 비밀번호는 영문 대소문자, 숫자, 특수문자 조합으로 생성되어 있습니다. 로그인 후 `[보안 & 접속설정]` 탭에서 언제든 기억하기 쉬운 비밀번호로 재변경하실 수 있습니다.

## 3. MS Word(.docx) 문서를 활용한 초간편 글 등록

새로운 공지사항이나 언론 보도자료를 등록할 때 가장 빠르고 권장하는 방법입니다.

```
[1. 카테고리 선택]  👉  [2. 워드 파일 드래그]  👉  [3. 내용 자동 추출 검토]  👉  [4. 즉시 웹사이트 발행]
  (공지/보도/리포트)       (.docx 문서)            (제목/날짜/본문/사진)           (0.1초 만에 사이트 반영)
```

### 📋 상세 진행 순서 (Step-by-Step)

1. 로그인 후 상단 탭에서 **`[신규 글 등록 (워드 업로드)]`**를 선택합니다.
2. **카테고리 선택**: 등록하려는 글의 성격에 맞춰 `[공지사항]`, `[언론보도]`, `[리서처 리포트]` 중 하나를 클릭합니다.
3. **워드 파일 업로드**:
   - 파란색 점선 박스(`MS Word (.docx) 파일을 이곳에 끌어다 놓으세요`) 영역에 작성하신 워드 문서를 **마우스로 드래그 & 드롭**하거나, 박스를 클릭하여 파일을 선택합니다.
4. **자동 추출 확인**:
   - 파일이 업로드되는 즉시 시스템이 문서를 분석하여 아래 항목을 자동으로 채워 넣습니다:
     - **제목(Title)**: 워드 문서의 가장 첫 머리글(제목 스타일) 자동 추출
     - **게시 날짜(Date)**: 문서 내 날짜(`YYYY.MM.DD`) 자동 인식 (미인식 시 오늘 날짜 기입)
     - **요약 설명(Description)**: 첫 번째 문단을 발췌하여 목록 카드용 2줄 설명 생성
     - **본문 내용(HTML)**: 표, 글머리 기호, 굵은 글씨 등 원본 서식을 살려 자동 변환
     - **대표 썸네일**: 워드 문서 안에 삽입되어 있던 첫 번째 사진을 자동으로 대표 썸네일 이미지로 설정
5. **라이브 미리보기 확인**:
   - 우측 화면에 **실제 웹사이트 메인 화면에 뜨게 될 카드 형태**가 실시간으로 렌더링됩니다.
6. **발행하기 클릭**:
   - 하단의 초록색 **`[즉시 웹사이트에 발행하기]`** 버튼을 클릭하면 완료 메시지와 함께 즉시 게시됩니다.

## 4. 카테고리별 등록 가이드

게시판의 특성에 따라 입력하는 세부 항목이 조금씩 다르므로 아래를 참고하시기 바랍니다.

### ① 공지사항 (Notice)
- **노출 위치**: 홈페이지 메인 **[남도 소식 & 공지] → [공지사항]** 탭
- **주요 용도**: 서포터즈 모집, 정원 투어 공모전, 운영 일정 변경 안내, 축제 일정 공지
- **입력 팁**:
  - `원문 링크 URL`: 관련 접수 페이지나 네이버 폼 링크가 있다면 입력 (없으면 비워둠)
  - 별도 외부 링크가 없는 경우, 방문자가 카드를 클릭하면 본문 내용을 읽을 수 있는 상세 페이지로 자동 연결됩니다.

### ② 언론보도 (Press Release)
- **노출 위치**: 홈페이지 메인 **[남도 소식 & 공지] → [언론보도]** 탭 (3열 카드 갤러리)
- **주요 용도**: 방송 보도(KBC 등), 신문 기사, 온라인 보도자료 게재
- **입력 팁**:
  - `언론사명 (Source)`: 예) *KBC광주방송*, *뉴스와이어*, *전남일보* 등 입력
  - `기사 원문 링크 URL`: 포털 뉴스나 언론사 공식 기사 링크(`https://...`) 입력
  - `대표 썸네일`: 워드 내 사진이 자동으로 들어가며, 별도 보도 사진 파일(JPG/PNG)을 추가 업로드할 수도 있습니다.

### ③ 리서처 리포트 (Researcher Story)
- **노출 위치**: **[AI 리서처 추천]** 섹션 및 **[리서처 리포트 전체 아카이브(`/posts`)]**
- **주요 용도**: 신규 민간정원 탐방기, 지역 미식 투어 추천, 테마별 여행 코스 기사

## 5. 등록된 게시글 관리 및 삭제

이미 등록한 게시글을 확인하거나, 테스트로 올린 글 또는 기간이 지난 공지를 삭제하는 방법입니다.

1. 관리자 상단 탭에서 **`[등록된 글 관리 (숫자)]`**를 클릭합니다.
2. 지금까지 관리자 모드를 통해 등록된 **공지사항, 언론보도, 리포트 목록이 최신순으로 정렬**되어 나타납니다.
3. **미리보기 / 링크 열기**: 
   - 우측의 외부 링크(`🔗`) 아이콘을 클릭하면 실제 웹사이트에서 어떻게 열리는지 바로 새 창으로 확인하실 수 있습니다.
4. **삭제하기**:
   - 우측의 빨간색 **`[삭제]`** 버튼을 클릭하고 확인창에서 승인하면, **홈페이지에서 즉시 영구 삭제** 처리됩니다.
5. **데이터 백업 (JSON 다운로드)**:
   - 우측 상단의 `[데이터 JSON 백업 다운로드]` 버튼을 누르면, 지금까지 등록된 모든 글 데이터가 백업 파일(`.json`)로 다운로드되어 안전하게 보관하실 수 있습니다.

## 6. 보안 설정 (접속 주소 및 비밀번호 변경)

보안 관리를 위해 관리자 접속 URL과 계정 비밀번호를 주기적으로 변경하실 수 있습니다.  
로그인 후 상단 **`[⚙️ 보안 & 접속설정]`** 탭을 클릭합니다.

### 1) 관리자 접속 주소(URL) 변경
- 일반적인 주소인 `/admin` 대신, **우리 기관만의 비밀 경로**를 만들어 외부인의 무단 접근을 방지할 수 있습니다.
- **설정 방법**:
  1. `새 접속 경로 (URL Path)` 입력창에 원하는 경로 입력 (예: `/namdo-manage`, `/partner-portal`)
  2. **`[관리자 접속 경로 저장]`** 버튼 클릭
  3. 이제 `https://namdoartgarden.com/namdo-manage` 주소로 관리자 포털에 접속할 수 있습니다. (우측 '복사' 버튼으로 주소 복사 가능)
  - *(※ 관리자 편의를 위해 기존 `/admin` 경로로도 안전하게 접근할 수 있도록 이중 보존됩니다.)*

### 2) 관리자 아이디 및 비밀번호 변경
- **설정 방법**:
  1. `관리자 아이디 (ID)`에 사용할 새 아이디 입력
  2. `현재 비밀번호 (확인용)`에 지금 로그인한 비밀번호 입력
  3. `새 비밀번호` 및 `새 비밀번호 재입력`란에 변경할 비밀번호 입력
  4. **`[계정 정보 변경 저장]`** 버튼 클릭
  5. 즉시 새 계정 정보가 적용되어 다음 로그인부터 사용됩니다.

### 3) 기본 설정값 복원 (초기화 안전장치)
- 만약 변경한 비밀번호나 접속 주소를 분실했을 경우, **`[기본값 복원]`** 버튼을 누르면 초기 공장 출고값(`admin` / `namdo2026!` / `/admin`)으로 즉시 복원되어 시스템 잠김 위험이 없습니다.

## 7. 워드 원고 작성 권장 서식 및 주의사항 (FAQ)

### Q1. 워드 문서 작성 시 지켜야 할 권장 양식이 있나요?
- **제목**: 문서 첫 줄에 큰 글씨 또는 워드의 **[제목 1(Heading 1)]** 서식으로 작성하시면 시스템이 정확하게 제목으로 인식합니다.
- **날짜**: 문서 상단에 `2026.04.19` 또는 `2026-04-19` 형식으로 적어두시면 자동으로 게시 날짜로 인식됩니다.
- **사진**: 본문 중간에 마우스로 사진을 붙여넣어 두시면, 가장 첫 번째 사진이 자동으로 웹사이트 대표 카드 썸네일로 연결됩니다.

### Q2. 한글 파일(.hwp / .hwpx)도 바로 올릴 수 있나요?
- 본 시스템은 국제 표준 문서 형식인 **MS Word 파일(`.docx`)을 기준**으로 자동 파싱을 지원합니다.
- 한글(`.hwp`)로 작성된 원고는 한글 프로그램에서 **[파일] → [다른 이름으로 저장] → 파일 형식을 `워드 문서(*.docx)`로 선택**하여 저장하신 후 업로드하시면 동일하게 완벽 작동합니다.

### Q3. 글을 등록했는데 홈페이지에 바로 보이지 않아요.
- 브라우저에 이전 페이지가 캐시되어 남아있을 수 있습니다. 홈페이지 메인에서 키보드의 **`Ctrl + F5` (강력 새로고침)**를 누르시면 방금 등록한 최신 글이 즉시 나타납니다.
